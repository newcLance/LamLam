识别 · 01

当前运营阶段诊断

核心判断：旅谣正处在"多轮删档测试期 → 公测"之间最微妙的运营窗口。它手握 211 万 TapTap 预约与 8.9 分的高预期，但也背着二测暴露的"逼肝"体感和挥之不去的"缝合"标签。这个阶段的核心命题不是"拉新"，而是"把测试口碑变成可累积的信任资产，别让预期在删档反复里被磨掉"。

时间轴：旅谣现在站在哪

节点事件运营含义
2024-03首曝 PV + 全平台预约开启（B站 PV 千万级播放）声量峰值，建立第一印象
2024-05官方 B 站粉丝破 100 万 萌娘百科 ↗核心粉丝盘成型
2025-08星至测试（一测，仅 PC，不计费删档）验证美术口碑，暴露"开放世界没劲/优化"问题
2026-04恒序测试（二测，PC+移动端，不计费删档）内容密度提升，但"逼肝"成最大吐槽点
2026-07（现在）旅迹测试（三测，限量计费删档）付费验证 + 公测前最后一次口碑校准
未定正式公测热度与信任能否兑现的终考

这个阶段的三个真实病症

  • 病症一：口碑在"惊艳"与"吐槽"之间摇摆——一测 GameLook 记录"上手后玩家惊呼超预期"，但同期也有"开放世界没回过劲""捡垃圾收集材料""优化问题"的质疑；二测称"内容密度高的答卷"，但"重度肝"成为最大实测吐槽 GameLook 一测实测 ↗
  • 病症二：删档计费在消耗信任——三测已开始计费但结束删档，玩家投入的付费与养成会清零，这是社区焦虑的高发点 TapTap 官方页 ↗
  • 病症三：战线太长，热度有保质期——三测跨越近一年，公测时间未定，"测试疲劳"正在积累

阶段结论：旅谣不缺声量（211 万预约摆在那），缺的是"把每一轮测试都变成一次可见的进步证明"的运营能力。当前阶段的每一分预算，都应该花在"让观望玩家看到旅谣在认真改，而不是在反复删档里空转"上。

识别 · 02

目标用户行为路径

核心判断：当前阶段要盯的不是"新增预约"，而是"预约用户会不会掉队"。211 万预约里，真正会在公测日打开游戏的比例，取决于他们在这段测试期里接收到的是"越来越期待"还是"算了再看看"的信号。运营要沿着"预约 → 关注测试 → 参与/围观 → 公测激活"这条链路，逐环节堵漏。

预约用户的四段行为路径

阶段用户状态流失风险点运营抓手

关注测试·围观期没资格/没参与测试，靠 UP 主实机围观被负面实测（逼肝/缝合）劝退控制 UP 主内容口径，让"减负/治愈"卖点先于"逼肝"吐槽触达
参与测试·体验期拿到测试资格，亲手玩删档挫败、逼肝弃坑删档补偿承诺 + 收集/家园的即时成就感设计

三类用户的差异化行为动机

  • 碧蓝老盘：会持续关注但高敏感，行为取决于"蛮啾有没有守住调性"——一个性别向传言就可能让他们从"期待"转"观望"
  • 捉宠收集党：会横向对比帕鲁再决定，行为取决于"奇波深度有没有说服他们"——TapTap 已有"自由度比帕鲁低"的实测原声 TapTap 原声 ↗
  • 治愈休闲盘：最容易被"减负/生活感"打动，也最容易被"逼肝"劝退——二测"重度肝"的吐槽恰恰精准打击了这圈人的核心诉求

路径结论：旅谣的运营漏斗漏点集中在"围观期"和"体验期"两环——负面实测在围观期先入为主，删档逼肝在体验期消耗耐心。运营的钱要优先花在这两环的堵漏上，而不是继续在已经饱和的"预约拉新"上加码。

定位 · 03

阶段情感钩子

核心判断：测试期的情感钩子不能再是首曝时的"惊艳"（那张牌已经打过了），而应该是"陪伴式共建"——让预约玩家觉得"旅谣是和我一起长大的，我的反馈它真的听进去了"。这个阶段卖的不是产品，是"参与感"和"被重视感"。

为什么"陪伴共建"是这个阶段的最优钩子

测试期玩家的心理很特殊——他们既是用户，也是"产品的早期见证者"。用好这重身份，能把删档的负面（"我的进度没了"）转化为正面（"我参与了它变好的过程"）：

  • 对冲删档焦虑：删档让玩家觉得"投入白费"，而"共建"叙事把它重构成"你的每次测试都在帮旅谣变好，公测那个更好的版本里有你的一份"
  • 对冲测试疲劳：战线长容易凉，但"看着它一测测变好"的养成式陪伴，反而能把长战线变成情感积累
  • 激活老盘认同：碧蓝老盘最吃"被重视"这一套——蛮啾当年就是靠听劝、听玩家意见积累了口碑

情感钩子的三层递进

层次情感诉求落地表达
被听见"我的吐槽有人管"每轮测试后公开"这次改了什么"，点名回应高频反馈（尤其逼肝问题）
被记得"我参与过的痕迹被保留"删档但保留"测试者身份/纪念徽章/公测专属称号"，让投入有情感残值
被期待"公测那个版本值得等"把每轮改进串成"通往公测的成长线"，让等待本身变成期待累积

钩子结论：一句话概括这个阶段的情感主线——"予你的星光牧场，是我们一起种出来的"。把首曝的"惊艳感"降级为背景，把"共建陪伴"升为主线，才能让 211 万预约在漫长测试期里不掉队、还越等越热。

定位 · 04

内容节奏策略

核心判断：测试期内容不能"憋大招等公测一次放"，而要"高频、小步、可见"——用密集的小内容让玩家持续感知"旅谣一直在动"。节奏的关键是把"角色 PV"这个已验证的爆款范式做成常态化连载，同时用"改进汇报"稳住信任。

定位 · 05

社区信任修复

核心判断：旅谣当前的信任账户上挂着三笔"欠账"——缝合质疑、逼肝焦虑、性别向敏感。信任修复不是靠公关话术，而是靠"用产品行动逐笔还债"：缝合用差异化实机还，逼肝用版本减负还，性别向用口径一致还。每还一笔，都要让社区看得见。

三笔信任欠账与还债方式

欠账一：缝合帕鲁质疑

TapTap 原声："奇波系统只算中规中矩""很难说不是换皮"。GameLook 给了"国产二次元帕鲁"标签。 TapTap 原声 ↗

还债方式：用"奇波性格羁绊 + 四阶进化 + 人宠共斗战斗"的深度实机主动讲差异，把"缝合"重构为"取长补短的进化"。不辩解玩法像不像，而是证明"体验完全不同"。

欠账二：逼肝焦虑

二测最大实测吐槽："重度肝、养成材料同源体力不够、家园/坐骑双重饱食度、异色闪光内卷"。 TapTap 实测 ↗

还债方式：这是唯一必须靠"改产品"还的债。公测前重构养成/家园节奏，把二测的"重度肝"改成真正的减负，然后用"我们把肝度降下来了"作为公测前最重磅的口碑事件公布。

欠账三：性别向敏感

2024 首曝"疑似加入可抽男性角色"传言引发舆论风暴，蛮啾连发两声明澄清。 GameLook ↗

还债方式：口径绝对统一——"卡池只出女性角色"不留解读空间。所有角色内容发布前做敏感度预审，建立传言 24 小时响应机制。

修复结论：信任修复的顺序很重要——逼肝（产品债）优先级最高，缝合（认知债）次之，性别向（沟通债）持续维护。逼肝若不改，其他两笔还得再好也没用，因为玩家真上手就会被劝退。产品端还债，宣发端才有底气把债务翻篇。

构建 · 08

转化漏斗设计

核心判断：旅谣的转化漏斗不是"曝光→下载"的标准模型，而是"预约存量 → 测试期不掉队 → 公测激活"的存量运营模型。211 万预约是漏斗顶部的水池，运营的任务是别让水在测试期漏光，并在公测日把它精准放出来。

四层转化漏斗

漏斗层当前量级转化目标关键动作
预约池TapTap 211 万预约 / 209 万关注（B站另有百万级粉丝）TapTap ↗维持不流失常态化内容唤醒
活跃关注持续看 PV/实机的活跃预约用户转化为"越等越期待"角色 PV 连载 + 共建日志
测试参与/围观参与三测 + 围观 UP 主的用户形成正面体验记忆减负改进 + 共建者档案
公测激活公测日实际打开的用户首周留存 + 首充转化召回礼 + 首日活动 + 裂变

每层漏斗的堵漏优先级

  • 最该堵的漏点：测试参与/围观层——这是负面实测（逼肝/缝合）造成流失的重灾区，减负改进 + 差异化实机要优先砸资源
  • 次优先：活跃关注层——用高频内容维持"它还在动"的存在感，防止预约用户遗忘
  • 临门一脚：公测激活层——召回礼与首日体验决定 211 万预约里有多少真的变成 DAU

漏斗结论：旅谣不需要在漏斗顶部继续砸钱拉预约（211 万已够撑起一次成功公测），要把预算集中砸在"中段防漏 + 末段激活"。一个残酷的现实：预约量再高，若测试期口碑崩了，公测激活率也会腰斩——所以运营的胜负手在中段的信任修复，而非顶部的声量。

收尾 · 09

风险预警与应对

风险一：减负没改到位，公测口碑崩盘（高风险）

逼肝是二测最大实测吐槽，若公测版本仍未真正减负，"减负宣传"会变成"虚假宣传"，反噬更狠——玩家会觉得被骗。这是所有运营动作的地基风险。 TapTap 实测 ↗

应对策略：

  • 减负改进必须先做到、再宣传——绝不能宣传领先于产品
  • 公测前小范围回归测试验证减负效果，用真实测试用户的反馈背书
  • 预留"公测后首月快速迭代"预案，一旦仍有肝度反馈立即热更
风险二：删档挫败累积，测试用户提前离场（中高风险）

三测计费删档，玩家付费与养成清零。若删档补偿/共建叙事做得不够，核心测试用户可能在公测前就心累离场。

应对策略：

  • 用"星原共建者"档案（创意一）把删档转化为荣誉，给投入以情感残值
  • 计费删档的付费给予公测双倍返还或专属补偿，明确告知规则不玩文字游戏
  • 每轮测试后的复盘必须真诚，让玩家看到"我的删档换来了它的进步"
风险三：公测时间未定，热度过保质期（中风险）

三测跨越近一年公测仍未定档，"测试疲劳"真实存在，竞品（无限大 ANANTA 已预计 2026 暑期公测）可能先占据用户时间。 游侠（ANANTA 进度）↗

应对策略：

  • 尽快给出公测定档信号，哪怕先给"季度窗口"，也比无限期观望强
  • 把长战线做成"成长叙事"——每轮测试的进步串成通往公测的故事线，让等待有意义
  • 与 ANANTA 错峰或差异化定位，避免暑期档正面撞车分流
风险四：商业化公布引发氪金焦虑（中风险）

商业化机制官方至今未公开，一旦公布若被解读为"逼氪"，会叠加"逼肝"焦虑形成双重劝退。 18183（商业化未定）↗

应对策略：

  • 商业化公布克制透明，付费点向外观/家园/收集倾斜，避开战力氪金
  • 坚守"卡池只出女性角色"承诺，同时明确付费不影响核心养成节奏
  • 公布前做核心盘小范围沟通预热，避免"突然袭击"式引爆焦虑

顾问终审意见

终审判断：GO（前提是产品端先还清逼肝这笔债）

从运营阶段看，旅谣的底子很好——211 万预约、8.9 分、百万级 B 站粉、可复制的角色 PV 爆款范式，这些都是别人求之不得的运营弹药。但当前阶段的胜负手不在"怎么放大声量"，而在"怎么在测试期把信任守住"。逼肝这笔产品债不还清，再漂亮的运营节奏都是在漏水的池子里加水。

三个尖锐问题

1. "共建陪伴"叙事能不能扛住又一次删档？
共建叙事很动人，但玩家的耐心是有限的。如果三测之后还有四测、五测，"共建"会从感动变成消耗。建议：把三测明确定位为"最后一次删档测试"，给玩家一个确定的终点，让共建叙事有兑现的时间表。

2. 减负和"手游长线留存"的矛盾在运营端怎么解？
减负是修复口碑的必需，但运营需要玩家有持续目标才能长线留存。减太狠会"毕业快"，减不够会"劝退"。建议：把长线动力从"体力/日常肝"迁移到"奇波收集完整度 + 家园养成成就 + 社交攀比（闪光名录）"，用兴趣驱动替代任务驱动。

3. 公测定档迟迟不定，是产品没打磨好还是在等档期？
如果是前者，运营再努力也救不了未完成的产品；如果是后者，长期观望会消耗热度。建议：运营团队需要向制作端要一个明确的公测窗口，才能倒推所有排期——没有锚点的运营节奏是无根之木。

最终建议：这个阶段的运营核心是一句话——"把每一次删档，都变成一次让玩家看得见的进步。" 旅谣不缺预约、不缺声量、不缺角色弹药，它缺的是"让 211 万观望者相信旅谣在认真变好"的确定性。守住信任、还清逼肝债、把删档做成共建，公测那天 211 万预约才不会只是一个漂亮的数字。
